Password Hash Cracking

📄 Download Full Report (PDF)

Objective

Analyze password hashes and evaluate password security using password cracking techniques and dictionary attacks.

Tools Used

  • John the Ripper
  • Kali Linux
  • Wordlists
  • Hash Identification

Key Findings

  • Identified MD5 and SHA256 password hashes
  • Performed dictionary attacks using custom wordlists
  • Recovered weak passwords
  • Compared password strength and hashing algorithms
  • Researched password attack techniques and security implications

Conclusion

This investigation demonstrated how weak passwords can be recovered using dictionary attacks and highlighted the importance of strong password policies, secure password storage, and modern password hashing practices.

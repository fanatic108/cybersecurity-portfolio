Incident Response Investigation

Scenario

A simulated cyber attack was investigated using system logs, PowerShell execution records, malware activity, and privilege escalation events.

Tools Used

  • Kali Linux
  • Linux Command Line
  • Log Analysis
  • Timeline Reconstruction

Investigation Process

  1. Reviewed available evidence and logs.
  2. Identified suspicious PowerShell activity.
  3. Traced malware execution behavior.
  4. Analyzed privilege escalation events.
  5. Reconstructed attack timeline.

Findings

  • Malicious PowerShell execution detected.
  • Payload downloaded from external source.
  • Privilege escalation observed.
  • Attack timeline successfully reconstructed.

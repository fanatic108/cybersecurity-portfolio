TLS Handshake & Certificate Analysis

Objective

Capture and analyze a TLS handshake and evaluate the security of the website certificate.

Tools Used

  • Wireshark
  • OpenSSL
  • Kali Linux

Key Findings

  • Target Website: hackerone.com
  • Certificate Authority: DigiCert Global Root G2
  • Public Key Algorithm: RSA
  • Key Length: 2048-bit
  • TLS Version: TLS 1.3
  • Negotiated Cipher: TLS_AES_128_GCM_SHA256

Certificate Validation

Verified certificate validity period, certificate chain, cipher suites, and OCSP revocation status using OpenSSL.

Conclusion

The website certificate was valid, trusted, and not revoked. Modern TLS 1.3 encryption was successfully negotiated.

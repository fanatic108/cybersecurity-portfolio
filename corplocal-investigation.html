CorpLocal Attack Investigation

Scenario

A simulated attack against CorpLocal was investigated from initial phishing delivery through malware execution, privilege escalation, credential dumping, lateral movement, and database access.

Key Findings

  • Malicious attachment: Invoice_Q1-2026.docm
  • PowerShell Invoke-WebRequest executed
  • Malicious domain: umbrella-corporation.biz
  • Privilege escalation using fodhelper.exe
  • Credential dumping using mimikatz.exe
  • Database access using svc-admin
